# Pococha 時間稼ぎ・エール記録帳

自分垢×他人垢の稼ぎ記録・エール管理ツール。

© Yoshi1012

## 使い方

`index.html` をブラウザで開くだけで使えます（GitHub Pages で公開中）。

## 保存について

- GitHub Pages 版は、記録を **開いた端末のブラウザにだけ** 保存します。
- バックアップ・CSV・印刷用ファイルは、GitHub Pages 版でも端末に保存できます。
- オフライン版として使用します。端末を替える際はバックアップを書き出して復元してください。

## 日付別入力の改善（2026-10-02・第2回）

10回に分けて、以下を改善しました。

1. 入力に集中する表示と、固定パネルの任意表示。
2. 分／時間:分の切り替え。75、1:15、1時間15分を同じ時間として入力。
3. 前後の組み合わせへ移動し、記録済みも順番に修正。
4. −5／＋5／＋15分と、選択した組み合わせの前日コピー。
5. 0分で稼いだ日を記録する操作と、記録解除を明確に区別。
6. 前回入力した時間を再利用するボタン。
7. 入力欄の近くに実際の保存状態を表示。月間・自分垢別合計も入力中に更新。
8. 残り件数付きの入力開始ボタンと、入力欄内の日付・曜日表示。
9. 未入力の追加組み合わせと、月ごとの選択日・組み合わせを再読込後も復元。
10. まとめ入力にも任意の分数・時間:分を使用。対象確認と2回目のクリックで確定。

文字変換中の移動を防ぎ、入力の消失を修正しました。0分・解除・上書き・コピーは取り消せます。

`npm run debug:5` で、構造と日付、時間入力、検索と目標、IMEとエール、保存と復元の5回を検証します。公開画面はクラウドブラウザで別途確認します。


## 名前・目標設定の改善（2026-10-02・20項目）

他人垢を選び、自分垢ごとの目標エールを設定できます。入力方向を切り替えても、保存する自分垢→他人垢の組み合わせは同じです。

1. 他人垢を起点にする入力を初期表示。
2. 自分垢を起点にする表示も選択でき、編集中の組み合わせを維持。
3. 選択する垢の前後移動を追加。
4. 名前・使用状態・選択先の目標や実績から入力候補を表示。
5. 名前・番号検索と検索解除。
6. 未設定／設定済みの絞り込み。
7. 月と選択先、目標の向きが分かる見出し・読み上げ名。
8. 表示件数・個別目標の設定数・目標合計をコンパクトに表示。
9. 登録・変更した名前を選択欄と目標行に即時反映。編集中の値とフォーカスを維持。
10. エール数／k単位を切り替え、変換例と個別解除を明示。
11. Enterで次、Shift＋Enterで前、Escapeで未確定入力を取り消し。
12. 変換中・不正値で画面移動を止め、月・単位・選択先の古い入力イベントを拒否。実保存状態を表示。
13. 目標のまとめ入力を折りたたみ、常時表示していた候補・説明を整理。
14. 一括反映は対象数と値を確認して2回目で確定。対象変更・時間経過で確認をやり直し、変更なしなら書き込まない。
15. 設定の状況を3項目に整理。重複する移動メニュー・初期ガイド・集計画面の目標編集欄を削除し、詳細設定を名前一覧の後で折りたたむ。集計の変更リンクは同じ目標フォームへ移動。
16. 名前の一括登録で番号付き・タブ区切りとコピーした名簿を利用可能。
17. 長すぎる名前・番号重複・範囲外を反映前に検証し、変更先を全件確認。
18. 名前の文字数は編集中・上限付近だけ表示。重複名の該当番号を案内し、保存は許可。
19. 未登録への入力開始と、Shift＋Enterで前の名前へ移動。
20. 名前の一括反映を共通の「元に戻す」に接続し、変更対象だけ復元。

`npm run debug:20` は20の異なる対象に分けて検証し、各回帰シナリオを一度ずつ実行します。通常の全件確認は `npm test`。公開画面の操作・再読み込み・表示はPCのクラウドブラウザで別途確認します。小画面向けのレイアウトはHTML/CSSの静的確認であり、実機iPhoneでの検証ではありません。
